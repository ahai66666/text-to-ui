# Fixtures

Fixtures are intentionally small, disposable inputs used by contract checks,
visual checks, and Skill examples. They are not the production component
source and must not be advertised as cross-framework implementations.

The fixtures cover reusable component and framework contracts. The compact
`mail-workbench-native-scene/` fixture is retained only for regression tests of
the Pixso native-scene adapter; it is not a runnable application or product
demo, and does not include generated operation-plan dumps or local preview
output.
